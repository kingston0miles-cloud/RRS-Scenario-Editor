# Исправления этапа 36

## Графики поездов без автоведения

В RRS файл `timetable/<имя поезда>.xml` загружается в компоненты `Autopilot`.
В `Model::slotUpdateTrainTimetable()` симулятор передаёт расписание только тем
единицам состава, у которых существует компонент автопилота. Поэтому поезд,
запущенный без `auto = true`, не получает от движка автоматического построения
маршрутов приёма/отправления, даже если XML-график присутствует.

Редактор уже умеет генерировать Lua-события `buildTrainRoute()` по графику.
Раньше весь этот механизм вызывался только при включённом общем флажке экспорта
«Триггеры маршрутов по графикам». Из-за этого отключение флажка могло оставить
поезд без автоведения вообще без механизма открытия сигналов.

Теперь:
- события построения маршрутов для поездов без автоведения создаются всегда;
- общий флажок управляет дополнительными событиями для поездов с автоведением
  и согласованием их маршрутов по категориям;
- индивидуальный флажок «Не создавать события маршрутов по графику этого поезда»
  остаётся явным исключением и сопровождается предупреждением;
- окно экспорта показывает список и количество обязательных событий, даже если
  дополнительные события для поездов с автоведением отключены;
- предупреждение о графике без бота больше не создаёт впечатление, что сигналы
  тоже не будут переключаться.

## Рефакторинг

- `AutoTriggerOptions::forBots` переименован в `includeAutoModeTrains`:
  новое имя точнее отражает поведение параметра.
- Логика планирования событий вызывается единым путём; различие между обязательными
  событиями обычных поездов и дополнительными событиями поездов с автоведением
  задаётся параметром планировщика.
- Добавлены регрессионные тесты на экспорт обычного поезда с графиком при выключенном
  флажке дополнительных событий, а также на явное отключение событий для отдельного
  поезда.

## Ограничения проверки

Исходный архив не содержит собранного исполняемого файла. В среде подготовки нет Qt 6
и MinGW, поэтому CMake не смог сконфигурировать проект и выполнить компиляцию или
Qt-тесты. Исходники и тесты обновлены, но этот архив нельзя честно назвать проверенным
Windows-билдом.
